# Retail Sales Analysis using MySQL

## 📌 Project Overview

This project analyzes **1,000 retail sales records** using MySQL to identify sales trends, top-performing product categories, high-value customers, and payment method performance.

The goal is to use SQL queries to extract meaningful business insights from retail transaction data.

## 🛠️ Tools & Technologies

* MySQL
* MySQL Workbench
* SQL
* GitHub

## 🔍 Analysis Performed

The project answers the following business questions:

1. What is the total revenue?
2. How many total orders were placed?
3. What is the total quantity of products sold?
4. What is the average order value?
5. Which product categories generate the most revenue?
6. Who are the top 5 customers by spending?
7. How does revenue change month by month?
8. Which payment method generates the highest revenue?
9. Which category has the highest quantity sold?
10. Which order generated the highest revenue?
11. What is the average sales amount for each category?
12. How many unique customers are present in each category?

## 📈 Key Insights

The analysis helps identify:

* Overall retail revenue
* Best-performing product categories
* Highest-spending customers
* Monthly revenue patterns
* Most-used/highest-revenue payment methods
* Average order value
* Category-wise sales performance

## 🎯 Business Objective

The analysis can help a retail business understand its sales performance and customer purchasing patterns, allowing better decisions related to product categories, customer retention, sales strategy, and payment options.
